一、内存区域
1、JVM 的内存区域是怎么划分
的？
　　程序计数器、虚拟机栈、本地方法栈、堆、方法区。其中堆和方法区是线程共享的。
2、堆和栈有什么区别？
　　栈存局部变量和方法调用，线程私有；堆存对象实例，线程共享。
