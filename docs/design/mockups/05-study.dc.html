HashMap 的扩容机制是怎样的？

跳过讲解，讲完直接评分；没讲全的地方，老师会点出来
老师

先别看资料，凭你的印象说说：HashMap 什么时候需要扩容？扩容的时候要做哪些事？

你

元素太多的时候吧。扩容就是建一个更大的数组，把原来的元素重新放进去。

老师

方向是对的，再说具体一点。元素个数超过阈值时触发扩容，阈值等于容量乘以负载因子，默认是 16 × 0.75 = 12。扩容时容量翻倍，再把旧数组里的节点迁移到新数组。

迁移时，JDK 1.8 不需要给每个节点重新算一遍下标。容量总是 2 的幂，翻倍之后，一个节点要么留在原来的位置，要么移到“原下标 + 旧容量”的位置。程序靠什么判断一个节点该留下还是该挪走？

你

看 hash 和旧容量做与运算的结果，是 0 就留在原位，不是 0 就移到原下标加旧容量的位置。

老师

对，就是这个判断。再往下想一步：同一个桶里的节点按这个规则分成两组以后，它们在新数组里的先后
