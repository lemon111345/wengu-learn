HashMap 的扩容机制是怎样的？

老师

最后，不看前面的对话，把“HashMap 的扩容机制是怎样的？”完整讲一遍。

你的完整作答

元素个数超过阈值时触发扩容，阈值是容量乘以负载因子，默认 12。扩容时容量翻倍，再把旧数组的节点迁移过去。迁移时不用重新算下标，看 hash 和旧容量做与运算：结果是 0 就留在原位，不是 0 就移到原下标加旧容量的位置。
