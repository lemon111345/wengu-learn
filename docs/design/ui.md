# 温故 · 前端设计规范 v1

本文档是 M1 前端实现的依据。页面效果见 `screenshots/`；需要精确数值时查 `mockups/` 中的画布源码。

**关于 `mockups/`：** 这些文件是设计画布的专用格式（`<x-dc>`、`<sc-for>`、`{{...}}`、`DCLogic`），不是 Vue，也不能直接在浏览器中打开。颜色和尺寸直接写在每个元素上，示例数据是假的。**只用来查数值，不要照抄代码。** 正式代码一律使用本文档定义的 CSS 变量。

## 1. 设计原则

1. **这是每天都用的应用，不是官网。** 不用动态背景、渐变、发光、滚动淡入。页面保持安静，动效只用来回应用户的操作。
2. **信息有用才加。** 解决“单调”靠加入对用户有用的信息，并用版面层次组织它们，不靠装饰。
3. **即时感。** 操作立刻有反馈：评分后立刻显示“下次见”，保存在后台进行（乐观更新）；设置修改后自动保存（今天页的“每天新学”例外，见 5.2）；AI 回复的第一个字要尽快出现，等待时显示“老师正在回复”。
4. **键盘优先。** 用户是开发者。一个知识点从开始到评分，可以全程不碰鼠标（见第 6 节）。
5. **界面只讲产品，不讲部署。** 部署、配置、自部署相关的说明写在 README 中，不出现在界面上。
6. **学习时只做眼前这一件事。** 学习、收尾、接着问三个页面隐藏侧栏，内容居中一栏。

避免以下“AI 味”的做法：灰蓝底加白卡片加灰描边的后台系统长相；聊天气泡式的对话；每个区块都带图标的功能列表；单个词加粗变色的大标题；米黄底色加宋体加陶土橙的组合。

## 2. 设计变量

所有颜色定义为 `:root` 上的 CSS 变量，组件中不写死色值。Element Plus 通过它自己的 CSS 变量（如 `--el-color-primary`）映射到下表。M1 只做浅色模式，但从第一天起按变量组织，以后加暗色模式只需再定义一套变量。

### 2.1 颜色

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--wg-bg` | `#FFFFFF` | 页面底色、面板底色 |
| `--wg-surface` | `#F6F7F9` | 侧栏、学生回答块、“下一个”卡片、次级区域 |
| `--wg-text` | `#1C1D21` | 正文 |
| `--wg-text-muted` | `#5F636B` | 次要文字、说明、标签文字 |
| `--wg-border` | `#E4E6EA` | 面板描边、分割线 |
| `--wg-border-strong` | `#D5D8DD` | 输入框、次按钮描边 |
| `--wg-tag-bg` | `#EEF0F3` | 类型标签底色、进度条未完成段 |
| `--wg-primary` | `#1F6FB2` | 主色（石青）：链接、当前项、主按钮文字、进度 |
| `--wg-primary-hover` | `#16507F` | 链接悬停 |
| `--wg-primary-soft` | `#E7F0F9` | 主按钮底色、导航当前项底色、选中态底色 |
| `--wg-primary-line` | `#C6D9EE` | 主按钮内 kbd 的描边 |
| `--wg-warn` | `#C2410C` | 需要用户注意的事：待确认提示、删除、明天到期 |
| `--wg-warn-soft` | `#FDF0E8` | 待确认提示条、未覆盖题目提示的底色 |
| `--wg-success` | `#2B8A3E` | 仅用于模型连接状态的色点 |

**评分与掌握程度共用一条色阶**：越暖越需要注意，越接近主色越好。

| 评分 | 掌握程度 | 变量 | 值 |
| --- | --- | --- | --- |
| 忘了 | 生疏 | `--wg-level-1` | `#D9480F` |
| 困难 | 一般 | `--wg-level-2` | `#E8A100` |
| 良好 | 熟悉 | `--wg-level-3` | `#7FB0DD` |
| 简单 | 牢固 | `--wg-level-4` | `#1F6FB2` |
| — | 待学 | `--wg-level-new` | `#C9CDD3` |
| — | 暂停 | 空心圆，描边 `#8A9099` | |
| — | 只收录（临时） | 空心圆，描边 `#C9CDD3` | |

色阶颜色只用于色点、色条、柱子，**不用作文字颜色**（琥珀色在白底上对比度不足）。色点旁边总是配文字，不单靠颜色传达信息。

**学习时长热力（月历）** 五级：`#EEF0F3`（没学）、`#DCEAF7`、`#A9CBEA`、`#5C97CF`、`#1F6FB2`。只有最深一级上的日期数字用白色，其余用 `--wg-text`。

### 2.2 字体

| 用途 | 字体 |
| --- | --- |
| 正文、界面 | `'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif` |
| 宋体（只用在少数地方） | `'Noto Serif SC', 'Songti SC', 'SimSun', serif`，字重 700 |

宋体只用于：“温故”标识、页面主标题（h1）、知识点标题、“X 月 X 日再见”、个别大数字。正文、按钮、表单一律用黑体。

字号：12、13、14、15、16、17、19、20、22、26、30、34、44（px）。常用的是：正文 15～16，说明 13～14，面板标题 16～18，页面标题 20～34。

行高：对话正文 1.85；其他正文 1.7～1.75；标题 1.3～1.45。

### 2.3 间距、圆角、尺寸

- 间距取 4 的倍数：4、8、12、16、20、24、28、32、40
- 圆角：kbd 4；分段控件内的选项 6；按钮、输入框 8；内层卡片 10；面板 14；标签和筛选按钮 999（胶囊形）
- 可点击元素的高度不小于 44px（筛选按钮、批量操作按钮可以是 40px）
- 面板：白底、1px `--wg-border` 描边、圆角 14，不加阴影。只有弹出菜单和弹窗用阴影 `0 8px 24px rgba(28,29,33,0.08)`

## 3. 组件

| 组件 | 规格 |
| --- | --- |
| 主按钮（浅底） | 底色 `--wg-primary-soft`，文字 `--wg-primary`，加粗，高 48（页面主操作）或 44，内含 kbd 快捷键提示 |
| 次按钮 | 白底，1px `--wg-border-strong` 描边，文字 `--wg-text` |
| 危险操作 | 只用文字按钮，颜色 `--wg-warn`，如“删除”“退出登录”，放在操作区的最右侧 |
| kbd 快捷键提示 | 12px，内边距 1px 7px，1px 描边（在主按钮内用 `--wg-primary-line`），圆角 4 |
| 类型标签 | 胶囊形，底色 `--wg-tag-bg`，13px，文字 `--wg-text-muted` |
| 色点 | 8px 圆点，后面跟文字（评分或掌握程度） |
| 分段进度条 | 一段代表一个知识点；已完成 `--wg-primary`，当前 `#A9CBEA`，未开始 `--wg-tag-bg`；今天页高 10，学习页顶栏高 6 |
| 分段控件 | 如“周 / 月”：底色 `--wg-tag-bg`，选中项白底加粗 |
| 筛选按钮 | 胶囊形，带色点和数量；选中时描边和底色变为主色系 |
| 提示条 | 底色 `--wg-warn-soft`，前面一个 `--wg-warn` 色点，右侧是操作链接；不使用左侧粗边框 |
| 对话消息 | 老师的话按正文排版，上方 13px 灰字写称呼；学生的回答放在 `--wg-surface` 圆角块中，上方写“你”。不使用聊天气泡 |
| 输入框 | 高 44，1px `--wg-border-strong` 描边，圆角 8；多行输入框可纵向拉伸 |

## 4. 布局

### 4.1 应用框架（今天、导入资料、确认知识点、知识库、设置）

- **左侧导航**宽 232～248px，底色 `--wg-surface`，右侧 1px 描边，贴屏幕左边。从上到下：“温故”标识、导航项、底部账户区。
- **M1 的导航项**：今天、知识库、导入资料、设置。“统计”之后再加（决策 038）。
- **账户区**：头像（取用户名首字）、用户名。点击弹出菜单：快捷键、退出登录；M4 加入个人资料、模型与 API Key、反馈。模型出错时头像上显示红点。
- **内容区**：顶栏高约 68（含 1px 底边），左右内边距 40；主体最宽 1400，居中。主体是“主列 + 右侧栏”：主列弹性占满，右侧栏 320～400px。

### 4.2 学习模式（学习、收尾、接着问）

- 隐藏左侧导航。
- 顶栏：左边“← 今天”，中间当天的分段进度和“9 / 11”，右边“本次 X 分钟”。
- 内容居中一栏，最宽 760px。这里留白是有意的：读和写都需要合适的行宽。
- 输入区在页面底部，上方 1px 分割线。

### 4.3 窄屏

M1 以桌面为主，但不能在窄屏上坏掉：侧栏和右侧栏在宽度不够时换行到主列下方；宽表格在自己的容器内横向滚动，页面本身不横向滚动。

## 5. 页面

每个页面列出：结构、需要的数据、交互和状态。接口名称以技术方案为准，这里只写需要什么数据。

### 5.1 注册与登录（截图：`01-register.png`、`02-login.png`）

- 左右两栏。左栏底色 `--wg-surface`：“温故”标识、一句标语、一张示例卡片（知识点标题、四个评分按钮、“11月7日再见”）。右栏是表单。
- **左栏做成独立组件**，标语和示例卡片的内容集中在一处。以后扩展到其他学习方向时，只改这个组件。
- 注册：用户名、密码（提示“至少 8 位”）、确认密码，“注册并开始”，下方“注册即表示同意《用户协议》和《隐私政策》”（M1 链接可以先指向占位页）。
- 登录：用户名、密码、“登录”。两者底部互相切换。
- 注册时从浏览器读取时区（`Intl.DateTimeFormat().resolvedOptions().timeZone`），静默提交，界面上不提示。
- 不出现管理员、部署、配置相关的任何文字。注册关闭时（由环境变量控制），注册页显示“暂未开放注册”。
- 注册成功后进入今天页（新用户看到空状态）。

### 5.2 今天（截图：`03-today.png`、`04-today-empty.png`）

**主列：**

1. **概况面板**：左边是宋体大标题（如“还剩 3 个新知识”）、一行说明（“复习 8 个已完成，今天已学 38 分钟”）、分段进度条和“8 / 11”；右边是“下一个”卡片：知识点标题、标签（新学或复习、类型）、主按钮“继续学习 Enter”。

   标题和说明按今天的进度变化（#49）：

   | 情况 | 大标题 | 说明行 |
   | --- | --- | --- |
   | 复习和新知识都还有 | 还剩 3 个复习、2 个新知识 | 已完成的部分和今天学了多久，如“复习 5 个已完成，新学 1 个已完成，今天已学 38 分钟”；什么都还没做时写“今天共 N 个，先复习后学新的” |
   | 只剩一种 | 还剩 3 个新知识 / 还剩 3 个复习 | 同上 |
   | 今天的都做完了 | 今天的都学完了 | “今天已学 38 分钟，明天有 N 个要复习”；没学满一分钟时只写明天（“明天没有要复习的”）；不显示“下一个”卡片 |
   | 有知识点，但今天没有要学的 | 今天没有要学的 | 同上 |

   主按钮今天还没学过时写“开始学习”，学过至少一个后写“继续学习”。
2. **从一个问题开始**：一行输入框加“开始学”按钮（功能是否做，M2 末看自用数据决定，#54；v0.1 发布前先去掉禁用的输入框，#92）。
3. **待确认提示条**：有未确认的草稿或候选知识点时出现，如“有 1 份导入结果等你确认，共 23 个知识点；学习时还记下了 2 个候选知识点”，右侧“去确认”。
4. **新学、复习两个列表并排**（宽度不够时上下排）。复习列表中今天已完成的，显示对勾、灰色标题和今天的评分。

**右侧栏：**

1. **接下来 7 天要复习的**（M1）：7 根柱子，最多的一天用主色；下面是“每天新学”加减按钮。改了数字之后旁边出现“保存”和“取消”，点“保存”才生效。这里不自动保存：这个数一改，今天的新知识列表就跟着变，连续点击时列表会来回跳（#49）。设置页没有这个问题，仍然自动保存。
2. **学习时长**（完整版在之后；M2 只做最小版，时长和连续学习天数，#87 中先补这里）：周 / 月切换。月视图是当月日历热力图，鼠标悬停显示当天时长；周视图是 7 根柱子。下面是本周、本月时长和连续学习天数。
3. **知识库**（之后）：分段色条（牢固、熟悉、一般、生疏、待学），图例带数量，下面一行写暂停和只收录的数量，最后是“按每天新学 3 个，还要 13 天学完”。

M1 不显示第 2、3 块，右侧栏只有第 1 块。

**数据：** 每日计划接口需要返回：学习日 `date`、待复习和待新学的列表、**今天已完成的列表**（含今天的评分、是否新学）。进度 = 已完成 ÷（已完成 + 待复习 + 待新学）。另需“接下来 7 天每天到期数量”和“待确认草稿列表”两个接口。

**日期一律使用接口返回的学习日**，不使用浏览器的当前日期。凌晨 1 点打开时，浏览器是第二天，学习日还是前一天。

**空状态**（没有任何知识点时）：主列是“先放进一些要学的东西”，三步说明（导入资料、确认知识点、每天打开学），主按钮“导入资料”；下面是“手上没有现成的资料？”和“从一个问题开始”。右侧栏是“每天新学几个”（可以在导入前设置）和一段“温故怎么安排复习”的说明。

### 5.3 学习（截图：`05-study.png`）

- 标题区：标签（新学或复习、类型），宋体知识点标题，下面一个次按钮“这个我会，直接完整作答”及一行说明“跳过讲解，讲完直接评分；没讲全的地方，老师会点出来”。
- **不显示学习阶段的进度**（摸底、讲解……）。模型无法可靠地报告自己处在哪个阶段。
- 对话区按第 3 节“对话消息”的样式。流式输出时，最后一条老师消息末尾显示一个主色的竖线光标，输入框下方显示“老师正在回复”。
- 底部输入框，标签“你的回答”，主按钮“发送 Ctrl Enter”。
- **完整作答模式**：模型输出【完整作答】标记后，输入框的标签变为“完整作答：不看上面，把整个问题讲一遍”，**上面的对话折叠起来**（显示“前面的 N 轮对话已折叠”），避免照着抄。作答提交后恢复显示。
- 点“这个我会，直接完整作答”：程序让模型直接进入完整作答，会话上记录“跳过了讲解”。
- 模型输出【学习结束】后进入收尾。
- “老师”二字使用设置中的称呼。

### 5.4 收尾与评分（截图：`06-finish.png`）

- 标题区同学习页。对话区显示最后几条：完整作答和老师的收尾点评。
- **评分面板**：标题“这次学得怎么样？”；灰底块中写“AI 建议：良好。”加依据，以及“没掌握的：……下次复习会重点问这里”。
- **四个评分按钮**：左上角 kbd 1～4，色点加评分名，下面是间隔（“明天 / 3 天后 / 8 天后 / 15 天后”，来自评分预览接口），AI 建议的那一个下面标“AI 建议”。**不预先选中。** 未选时下方提示“按 1～4 选择，评分后会算出下次复习的日期”。
- **选中后**（乐观更新，立刻显示，后台保存）：宋体 44px 主色“11月7日再见”，下面一行“到时会换个角度问，重点问这次没掌握的地方”。这里可以有本产品唯一的一处动效，比如日期从按钮位置浮上来；用户设置了减少动效时不播放。
- **候选知识点**：“这次聊到的，要不要加入知识库？”下面说明“包括评分时发现的缺口和接着问里聊到的内容，已经去掉重复。不确认也没关系，会保留在今天页的‘等你确认’里”。复选框列表，AI 认为不值得加入的折叠在下面并写明原因，可以展开勾选。按钮“加入知识库”。
- 操作：次按钮“接着问”，主按钮“下一个 Enter”。“下一个”评过分才能点；“接着问”学完就能点，不要求先评分（#23）。

**评分页是每个知识点的中转站**：主线是评分后按 Enter 进入下一个；支线是进入接着问，问完按 Esc 回到这里。

### 5.5 接着问（截图：`07-follow-up.png`）

- 顶部灰底卡片：宋体知识点标题、“已评分：良好，11月7日再见”，右侧“展开刚才的对话”（**原地展开**，不离开页面；展开后显示讲解、完整作答和收尾点评，中间几轮折叠）。
- 宋体标题“接着问”，说明“想问什么都可以，问到弄懂为止，不影响评分。老师只回答，不出题。”候选知识点做好后（#31）再在后面加上“返回后，聊到的新知识会整理出来，在评分页确认要不要加入复习”。
- 对话区，学生在前、老师在后。
- 底部：输入框（标签“继续问”），左边次按钮“← 返回评分页 Esc”，右边主按钮“发送 Ctrl Enter”。
- **不显示剩余次数。** 后端有一个较高的、不显示的上限；接近上限时，老师提示“这次聊得比较多了，可以先回去，把聊到的新知识加入复习，明天接着学”。
- 离开这个页面只有两种方式：底部“返回评分页”和左上角“今天”。
- 返回时，后台把这次接着问整理成候选知识点，完成后出现在评分页的候选列表中。

### 5.6 从一个问题开始（之后，M2 末看自用数据决定）

复用接着问的页面：去掉顶部的知识点卡片，标题改为用户输入的问题。结束时同样整理成候选知识点，出现在今天页的“等你确认”里。

### 5.7 导入资料（截图：`08-import-input.png`、`09-import-preview.png`、`10-import-extracting.png`）

顶栏左边是宋体标题“导入资料”，右边是三步进度：粘贴或上传 / 确认题目 / 抽取知识点。这里可以显示进度，因为程序自己知道走到了哪一步。

1. **粘贴或上传**：分段控件“粘贴文本 / 上传文件”；**资料类型**（分段控件“题目清单 / 讲解资料（笔记、文章）”，#26 新增，截图中没有）；资料名称；内容（多行输入框）；说明随资料类型变化：题目清单是“一行一题、带答案、表格、从网页复制的都可以，会自动识别出题目。答案会保存下来，但抽取时只看题目”，讲解资料是“没有现成题目的笔记、技术文章、书的章节：会根据内容整理出面试题，每道题都能用资料回答，下一步可以挑选”；主按钮“识别题目 Ctrl Enter”，讲解资料为“整理题目”。上传文件支持 PDF、Word（.docx）、Markdown、txt，最大 10 MB（选择时就检查），显示文件名、大小，可以移除；名称不填时用文件名；说明中写“扫描件（图片）的 PDF 暂不支持”。
2. **确认题目**：“识别出 47 道题”（讲解资料为“整理出”）和“已选 X 道”；说明“不是题目的去掉勾选就行。漏了题或者识别错了，可以回去改原文再识别一次”（讲解资料为“这些题是根据资料内容整理的，不想学的去掉勾选就行。不满意可以回上一步再整理一次”）；题目列表带复选框，追问显示在主问题下方；次按钮“回去改原文”（上传时为“回上一步”），主按钮“开始抽取知识点（X 道）Enter”。
3. **抽取知识点**：“正在抽取知识点”，说明分几批、大约还要多久，以及“可以先离开，完成后会出现在今天页的‘等你确认’里”；每一批一个进度块（完成的显示对勾和“抽出 N 个知识点”，进行中的显示不确定进度条，失败的显示原因和“重试这一批”）；按钮“回到今天”。

识别题目失败时，提示“题目识别失败，可以重试一次，或检查原文格式”，详细原因只写日志。原文过长时，提示“原文过长，可以删掉答案只保留题目，或分批导入”。

右侧栏：“导入之后会发生什么”的说明；“最近导入”列表（名称和状态：已确认 / 等你确认 / 抽取中 / 失败）。

### 5.8 确认知识点（截图：`11-confirm.png`）

- 顶栏“← 导入资料”。宋体标题“确认知识点”，说明来源、题数和知识点数，以及“已经按学习顺序排好。不想学的去掉勾选，确认后加入每日计划”。
- 列表按学习顺序，每一条：复选框、标题（加粗）、类型标签、要点（灰色）、“来自第 X、Y 题”。系统设计、个人经历类额外写“只收录”说明（临时状态，见第 8 节）。取消勾选的条目变淡。
- **M1 在这里只能取消勾选，不能修改**，修改在知识库中进行。这样草稿保持模型的原始输出。
- 右侧栏：大数字“N 个知识点将加入”、按类型的数量、“按每天新学 3 个，大约 X 天学完这一批”、主按钮“确认加入 Ctrl Enter”。
- 有题目没拆出知识点时，右侧栏下方显示提示条：列出这些题，说明“可能是被合并进了别的知识点，也可能是漏了”，按钮“单独再抽这 N 道”（用这些题的 `questionIds` 再发起一次抽取）。
- 接着问产生的候选知识点，也在同样的页面确认，来源写“接着问：<原知识点标题>”。

### 5.9 知识库（截图：`12-library.png`）

- 顶栏：宋体标题“知识库”，搜索框，主按钮“导入资料”。
- **筛选（列表上方一行）**：左边是掌握程度的筛选按钮（全部、牢固、熟悉、一般、生疏、待学、暂停、只收录），带色点和数量；右边是类型下拉框。两者同时生效。类型筛选生效时，下拉框变为主色描边和浅底。**按钮上的数量随类型筛选变化。**
- **排序（点表头）**：默认按学习顺序；点“掌握”按掌握程度排，再点反向；点“下次复习”按日期排。按掌握程度排序时，后端按 FSRS 稳定性排，待学、暂停、只收录排在最后。表头显示当前排序列和方向箭头。
- **列表列**：复选框、知识点标题、类型、掌握（色点加文字）、下次复习（明天到期用 `--wg-warn`）。点标题在右侧打开详情，当前行用 `--wg-surface` 底色。底部“显示 X 个，共 Y 个”，有筛选时加“（已筛选）”。
- **批量操作**：勾选后，列表上方出现主色浅底的操作条：“已选 N 个”、合并（选两个以上才可用）、暂停复习、恢复复习、删除、取消选择。暂停和恢复一直显示，勾选里混着暂停和没暂停的也能直接操作（#78）。表头的复选框是全选，只作用于当前显示的行（筛选和搜索之后）：没全选中时点它全部勾选，全选中时点它全部取消，部分选中时显示半选；在别的筛选下勾选的不受影响。删除不弹确认框，靠底部的撤销兜底，全选后也一样。
- **右侧详情**：
  - 掌握程度和“下次复习：X月X日”
  - 标题（宋体，可编辑）、类型（下拉）
  - 要点（可编辑），标签旁有小胶囊：默认“AI 生成”，改过后变为“你改过”并出现“恢复 AI 版本”。下方说明：“要点是评分的标准，由 AI 根据原题写成，可能有遗漏或错误。手上有参考答案的话，可以照着改；不要为了好过而删掉难的部分。”
  - 学习记录：日期和“新学，良好（AI 建议：良好）”
  - 来源：资料名称和题号，或“接着问：<原知识点标题>”
  - 操作：主按钮“保存修改”，次按钮“暂停复习 / 恢复复习”，右侧文字按钮“删除”
- **删除**：软删除，删除后底部提示“已删除”并提供几秒钟的“撤销”。
- **合并**：弹窗中选择一个作为主知识点，保留它的标题、要点和复习进度，其他的来源并到主知识点上。
- “恢复 AI 版本”的原文来自确认时关联的草稿条目，不需要另存。要点的每次修改都记录下来（#9 的数据）。

### 5.10 设置（截图：`13-settings.png`）

- 顶栏：宋体标题“设置”，右边状态“修改后自动保存”，改动后变为“已保存”。**没有保存按钮。**
- 两栏卡片：
  - **学习安排**：每天新学（加减按钮，旁边写“按现在的待学数量，还要 X 天学完”）；新的一天从几点开始（凌晨 0、2、4、6 点，说明“在这之前学的，算前一天。熬夜学习的话可以调晚一点”）；时区（显示为“中国标准时间（UTC+8）”这样的名字）。
  - **老师**：称呼（默认“老师”），说明“对话里会显示为‘X’，讲解方式不变”。只改变显示名称和模型的自称。
  - **账户**：用户名；次按钮“修改密码”；右侧文字按钮“退出登录”。
  - **AI 模型**：模型名和状态（色点加“正常”或错误原因），“最近一次调用：X 分钟前，成功”。**不显示服务地址和 Key。** M4 在这里加入“自带 API Key”。
  - **快捷键**：完整列表（见第 6 节）。
- M4 加入“反馈问题”。

## 6. 快捷键

| 场景 | 快捷键 |
| --- | --- |
| 今天页开始学习、评分后进入下一个 | Enter |
| 发送回答 | Ctrl + Enter（Mac 上为 Cmd + Enter） |
| 评分 | 1、2、3、4 |
| 从接着问返回评分页 | Esc |
| 搜索知识点 | Ctrl + K（M1 可以先在前端过滤知识点列表） |
| 查看全部快捷键 | ?（弹出快捷键列表） |

焦点在输入框中时，单键快捷键（1～4、?、Enter 进入下一个）不生效，避免和打字冲突。

## 7. 没有画出的状态

| 状态 | 处理 |
| --- | --- |
| 抽取某一批失败 | 导入进度中该批显示失败原因和“重试这一批”；今天页的提示条也显示 |
| 模型出错（401、超时、空回复） | 对话中显示一条可理解的提示和“重试”；头像上出现红点；设置的 AI 模型卡片显示原因。不显示 500 |
| 网络断开、SSE 中断 | 保留已收到的内容，显示“连接中断”和“重试” |
| 老师的回复丢了（后端重启、生成中途失败） | 进入页面或等待结束时，最后一条是学生的话、又没有在生成：显示“老师这条回复没有生成出来，可以点重试”和“重试” |
| 合并弹窗、删除撤销 | 见 5.9 |
| 快捷键帮助、搜索 | 居中弹窗，带阴影，Esc 关闭 |
| 列表为空、筛选无结果 | 一句说明加一个操作，如“没有符合条件的知识点”和“清除筛选” |
| 加载中 | 骨架占位，不用全屏转圈 |

## 8. 临时状态与 M1 范围外

- **只收录**：M1 中系统设计、个人经历类知识点暂时不能学，标为“只收录”。上线前这两类都要能学，这个状态会消失，不必在样式上花心思。
- **M2**：今天页的学习时长（最小版）；老师的称呼；截图导入（实现前先补进 5.7）。
- **M3**：“按参考答案重写要点”。
- **M4**：免费额度显示、自带 API Key、反馈入口、邮箱与找回密码。
- **M2 末看自用数据决定**：候选知识点（5.4 评分页的候选列表、5.5 返回时的整理）；“从一个问题开始”。
- **之后**：统计页和导航中的“统计”；今天页的知识库分布；组队打卡。

## 9. 文案

- 用中文全角标点；按钮写动作（“导入资料”“确认加入”），不写“确定”“提交”这类泛泛的词。
- 不用感叹号，不用表情符号。
- 说明文字直接告诉用户会发生什么，以及出了问题该怎么办。
