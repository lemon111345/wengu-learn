# 021 前端设计方向

## 背景

M1 要做前端，作者从零学起（决策 007）。动手之前先在设计画布上做了多轮比较，定下了布局、配色、字体和交互的方向，整理成 `docs/design/ui.md`（设计规范）、`screenshots/`（各页面截图）和 `mockups/`（画布源码）。本记录只写方向和取舍，具体数值以 ui.md 为准。

## 决策

1. **左侧导航的应用布局**：侧栏放标识、导航项和账户区；内容区是“主列 + 右侧栏”。学习、收尾、接着问三个页面隐藏侧栏，内容居中一栏
2. **石青配色**：主色 `#1F6FB2`。所有颜色定义为 CSS 变量，Element Plus 的变量映射到它们，组件中不写死色值；M1 只做浅色模式
3. **浅底主按钮**：主按钮用主色的浅底、主色文字，内含快捷键提示
4. **宋体标题**：宋体只用在“温故”标识、页面主标题、知识点标题、“X月X日再见”等少数地方，正文、按钮、表单一律用黑体
5. **评分与掌握程度共用一条色阶**：忘了 / 生疏、困难 / 一般、良好 / 熟悉、简单 / 牢固用同一组颜色，越暖越需要注意，越接近主色越好。色阶只用于色点、色条、柱子，不用作文字颜色
6. **键盘优先与乐观更新**：一个知识点从开始到评分可以全程不碰鼠标；评分、修改设置等操作立刻显示结果，保存在后台进行
7. **前端实现以 `docs/design/ui.md` 为准**。截图与规范不一致时以规范为准；`mockups/` 只用来查数值，不照抄代码

## 理由

- **这是每天都用的应用，不是官网**（ui.md 设计原则第 1 条）：页面要安静，动效只用来回应操作
- **左侧导航**：侧栏能放下账户区，也给以后的导航项（M2 的统计）留了位置；内容区可以用满宽度，放下主列和右侧栏。学习时隐藏侧栏，只做眼前这一件事
- **石青**：避开了后台系统的配方；主色同时是色阶中“简单 / 牢固”的一端，评分和掌握程度的颜色有统一的逻辑，不与其他档位撞色
- **浅底主按钮**：实心的主色按钮加上同色的进度条，蓝色面积过大
- **宋体只用在少数地方**：给安静的页面一点性格，又不影响正文的可读性
- **共用色阶**：评分是“这次记得怎样”，掌握程度是“长期记得怎样”，是同一件事的两面。用户在评分页看熟了颜色，在知识库里不用再学一遍。琥珀色在白底上对比度不足，所以不用作文字颜色，色点旁边总是配文字
- **键盘优先**：用户是开发者，每天要过十几个知识点，鼠标来回点很打断节奏
- **乐观更新**：评分和设置的保存几乎不会失败，让用户等着服务器回应没有必要
- **规范是唯一依据**：截图是画出来的某一刻，画布源码是设计工具的专用格式，只有规范是按 M1 范围整理过的

## 放弃的方案

| 方案 | 放弃原因 |
| --- | --- |
| 顶部导航、内容居中限宽 | 宽屏两边留白过多，是网站的排法；放不下“主列 + 右侧栏” |
| 营销页式的动态效果（动态背景、渐变、滚动淡入） | 适合只看一次的官网，在每天都用的应用里会变成干扰 |
| 黛蓝、竹青、靛蓝朱砂 | 同一个配方（灰蓝底、白卡片、灰描边、低饱和主色），是后台系统的长相，作者看着有“AI 味”；四档评分用四种互不相干的颜色，没有统一的逻辑 |
| 竹青（另外） | 主色与“良好”的绿色几乎一样 |
| 靛蓝朱砂（另外） | 朱砂红同时是“忘了”的颜色，用在“X月X日再见”上像出错 |
| 墨绿、划重点 | 作者对比后选了石青；划重点辨识度最高，但风险也最大 |
| 实心主色按钮 | 大块饱和的蓝色加上同色的进度条，蓝色面积过大 |
| 学习阶段进度条 | 模型无法可靠地报告自己处在哪个阶段（决策 018） |
